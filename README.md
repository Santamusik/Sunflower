# 🌙 달의 모양 변화 시뮬레이터

초등학교 4학년 학생들을 위한 달의 모양 변화 학습 프로그램입니다.

## 📋 주요 기능

### 1. 학생 정보 입력
- 학교, 학년, 반, 이름 정보 입력
- 세션 기반 학생 정보 관리

### 2. 달의 모양 변화 시뮬레이터
- 음력 30일간의 달의 모양 변화를 시각적으로 표현
- 재생/일시정지, 이전/다음 날 이동 기능
- 실시간 달의 위상 표시 (초승달, 상현달, 보름달, 하현달, 그믐달)
- **사실적인 달 렌더링**:
  - Canvas로 생성한 실제 달 텍스처 (크레이터, 마리아, 노이즈)
  - 3D 구형 효과를 위한 방사형 그라데이션
  - Terminator(명암 경계선) 그림자 효과
  - 정확한 음력 날짜별 위상 표현
- 음력 기준 정확한 달 모양:
  - 음력 3-4일: 초승달
  - 음력 7-8일: 상현달 (오른쪽 반)
  - 음력 15일: 보름달 (완전한 원)
  - 음력 22-23일: 하현달 (왼쪽 반)
  - 음력 27-28일: 그믐달

### 3. 퀴즈 시스템
- 10개 문제 풀에서 랜덤으로 3문제 출제
- 4지선다형 문제
- 정답 시 적절한 칭찬 메시지
- 오답 시 피드백 제공 및 1회 재도전 기회
- 2회 오답 시 정답 표시 및 설명 제공

### 4. 교사 대시보드
- 전체 학생 통계 (총 학생 수, 평균 점수, 만점 학생 수)
- 학생별 성적 및 응시 정보
- 부족한 개념 자동 분석
- 개념별 맞춤 지도 방안 제시
- 데이터 초기화 기능

## 🎯 학습 개념

프로그램은 다음 7가지 핵심 개념을 다룹니다:

1. **달의 주기**: 약 29.5일 주기로 모양이 변함
2. **달의 명칭**: 초승달, 상현달, 보름달, 하현달, 그믐달
3. **달의 순서**: 달의 모양 변화 순서
4. **달의 모양**: 각 시기별 달의 모양 특징
5. **달의 변화 방향**: 커지고 작아지는 방향
6. **달의 주기와 모양**: 날짜와 달 모양의 관계
7. **달의 변화 원리**: 태양 빛 반사에 의한 모양 변화

## 🚀 사용 방법

### 학생용
1. `index.html` 페이지에서 학생 정보 입력
2. 달의 모양 변화 시뮬레이터 관찰
3. 퀴즈 풀기 (3문제)
4. 결과 확인

### 교사용
1. `teacher.html` 페이지 접속
2. 학생별 성적 확인
3. 부족한 개념 분석
4. 지도 방안 확인

## 📁 파일 구조

```
Sunflower/

├── quiz.html              # 퀴즈 페이지

├── css/
│   └── style.css          # 전체 스타일시트
├── js/
│   ├── main.js            # 학생 정보 처리
│   ├── simulator.js       # 시뮬레이터 로직
│   ├── quiz.js            # 퀴즈 로직
│   └── teacher.js         # 교사 대시보드 로직
└── data/
    └── questions.js       # 퀴즈 문제 데이터
```

## 💾 데이터 저장

- **SessionStorage**: 현재 학생 정보 (세션 유지)
- **LocalStorage**: 퀴즈 결과 및 성적 데이터 (영구 저장)

1. 시뮬레이터를 천천히 재생하며 달의 변화를 관찰하도록 지도
2. 실제 달 관찰 일지와 연계하여 활용
3. 퀴즈 결과를 바탕으로 개별 맞춤 지도 실시
